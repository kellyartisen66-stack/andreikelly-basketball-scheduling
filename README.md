# Basketball Game Scheduling System

Project title: Design and Development of a Web-Based Basketball Game Scheduling System  
Researcher: Andrei Kelly Artisen  
School: La Consolacion College – Biñan

## Included prototype features
- Dashboard
- Team information management
- Game date and time scheduling
- Court assignment
- Same-court overlapping-time conflict detection
- Schedule filtering
- Team schedule viewing
- Local browser storage for prototype data

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
This is a front-end prototype. Data is stored in the current browser using localStorage.
For a final multi-user system, connect it to a server/database and add authentication.
